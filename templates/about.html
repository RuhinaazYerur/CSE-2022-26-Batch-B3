About the Project

Rice Cooking State Classification

An image-based deep learning system that predicts whether rice is Raw, Semi-cooked, or Fully cooked using transfer learning.

450
Total Images
3
Classes
ResNet50
Primary Backbone

🎯 Problem

  • Cooking-stage differences are visually subtle
  • Manual checking is subjective and inconsistent
  • No standard public dataset for rice cooking stages

✅ Objective

  • Build an accurate classifier for 3 cooking states
  • Provide confidence score for each prediction
  • Deploy a simple web app for demonstration

🏁 Outcome

  • Fast prediction from a single image
  • Supports quality monitoring and automation
  • Extensible to real-time and industrial use

🧠 Method Overview

  • Custom dataset creation (balanced classes)
  • Preprocessing and train/val/test split
  • Transfer learning (frozen base) + fine-tuning (top layers)
  • Evaluation with metrics and visual plots

🧰 Tools & Technology

  • Python, TensorFlow / Keras
  • ResNet50, VGG16, MobileNetV2 (trained models)
  • OpenCV for preprocessing
  • Flask for local deployment
  • HTML/CSS/JS for UI
